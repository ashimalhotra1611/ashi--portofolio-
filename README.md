# Ashi Malhotra | Portfolio Website

A responsive personal portfolio website that showcases my skills, projects, education and contact details.

🔗 **Live Demo:** [ashimalhotra1611.github.io/ashi--portofolio-](https://ashimalhotra1611.github.io/ashi--portofolio-/)

## ✨ Features

- Responsive layout that works on mobile, tablet and desktop
- Sections for Home, About, Skills, Projects, Education and Contact
- Working contact form (powered by FormSubmit)
- Downloadable resume

## 🛠️ Built With

- HTML
- CSS
- Bootstrap 5

1. Download or clone this repository
2. Open `index.html` in your browser
